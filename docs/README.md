# docs/

Aquí vive el `index.html` de las **slides del workshop**, publicado con
GitHub Pages.

## Cómo activar GitHub Pages sobre esta carpeta

1. En GitHub: **Settings → Pages**.
2. En *Build and deployment*: Source = **Deploy from a branch**.
3. Branch: `main`, carpeta **/docs** → **Save**.
4. Copia aquí el `index.html` de las slides y haz push.
5. Las slides quedan en `https://<usuario>.github.io/workshop-enterprise-ai-agents/`.
